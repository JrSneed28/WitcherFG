# Uninstall WitcherFG

This procedure is **Pending player acceptance** on the packaged candidate. WitcherFG makes temporary process changes and does not install a service or replace game files.

1. Close The Witcher 3 and all WitcherFG instances. Closing the game ends its session changes.
2. Remove any shortcut you created for WitcherFG.
3. Delete only the separate utility folder you extracted, including its executable, configuration, notices and instructions.
4. Optionally remove `%LOCALAPPDATA%\WitcherFG\diagnostics` and `%LOCALAPPDATA%\WitcherFG\support` after retaining any records you want. Remove the empty `%LOCALAPPDATA%\WitcherFG` folder if appropriate.
5. Keep or delete utility/configuration backup folders you created according to your preference. To restore a prior utility version, copy your own utility/configuration backup into a separate folder; review its schema before running it.
6. Launch the game normally through Xbox to check ordinary startup and rendering. This restoration check still needs measured acceptance.

No game-file restoration is required by the launcher. Preserve `dxgi.dll`, `d3d12.dll`, `sl.interposer.dll` and mod-loader files in the game installation. If you separately removed another mod while resolving a conflict, restore its backup using that mod's instructions. Do not delete or restore unrelated backups automatically.
