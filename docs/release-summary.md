# WitcherFG 0.1.0-preview.1 — unpublished preview

WitcherFG attempts guarded, temporary Streamline import routing for The Witcher 3 Xbox PC package 5.0.4.0. No stable release or public download is available. [Public support](https://github.com/JrSneed28/WitcherFG/issues) is available; vulnerabilities use [private security reporting](../SECURITY.md). Player packaging and exact-candidate gameplay/install/upgrade/uninstall acceptance are Pending.

The earlier RTX 5070 Ti / driver 617.42 / Windows 26200 / 1440p diagnostic probe restored FG/MFG with manual ray tracing recovery. That probe does not verify the native launcher or a player ZIP. Native synthetic lifecycle fixtures are separately documented. `Applied` and `RoutingAlreadyPresent` confirm routing only; FPS ratios do not prove generated frames.

For a developer-built executable, close the game, keep the utility outside the game directory on a fixed local drive, and run `WitcherFG.exe`. Preserve existing game/mod DLLs and backups. No chainloading or manager coexistence is verified. The compiled build guard refuses unknown builds and late startup.

Error logging is the default; automatic runtime observation is Off. The SDK diagnostic catalog is empty, so unavailable activity fields remain Unknown. Explicit `WitcherFG.exe --collect-support` creates a local sanitized archive without uploads. Normal returned exits 0/2/3/4 differ from forced watchdog 1460/fallback 124 and immediate unsafe helper 3; forced helper death does not prove target exit or detach.
