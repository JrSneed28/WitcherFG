# Security reporting

Use GitHub's [private vulnerability report form](https://github.com/JrSneed28/WitcherFG/security/advisories/new). Private vulnerability reporting is enabled for this repository. Do not post vulnerabilities, exploit details, credentials or unsanitized diagnostic records in public issues or discussions.

The current source is an unpublished preview. No stable release is available, and no response-time promise is supplied.

Relevant reports include unsafe DLL loading, process-identity confusion, memory corruption, mutation/rollback containment failures, unsafe file traversal/storage races, leaked private data and dependency tampering. Record affected build ID, exact reproduction and impact without unnecessary personal identifiers.

The launcher does not upload telemetry or support records. Support collection is explicit and schema-whitelisted; review the result before sharing. Ordinary reproducible bugs use the [public bug report form](https://github.com/JrSneed28/WitcherFG/issues/new/choose). Private vulnerabilities must use the private reporting route.
