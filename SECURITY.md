# Security reporting

**A verified private vulnerability-reporting channel is currently unavailable.** Public repository hosting and private-reporting setup are not configured. Do not post private vulnerabilities, exploit details, credentials or unsanitized diagnostic records in public issues.

Retain the report locally until a verified private channel is announced. This file will link that channel only after external setup and verification. No email address, security URL or response-time promise is supplied today.

Relevant reports include unsafe DLL loading, process-identity confusion, memory corruption, mutation/rollback containment failures, unsafe file traversal/storage races, leaked private data and dependency tampering. Record affected build ID, exact reproduction and impact without unnecessary personal identifiers.

The launcher does not upload telemetry or support records. Support collection is explicit and schema-whitelisted; review the result before sharing. Ordinary reproducible bugs use the [bug-form source](.github/ISSUE_TEMPLATE/bug_report.yml) when a real hosted form becomes available. Private vulnerabilities must not use that public route.
